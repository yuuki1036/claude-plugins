## 自己訂正の候補記録（failure-journal）

このセッション中に**自分の誤りを訂正した**とき（誤った前提で作業していた / ツール出力・ファイル内容を読み違えていた / 未検証の断定が後で崩れた / 同種の手戻りが 2 回目）、訂正したそのターン内で候補を 1 行 append すること。ユーザーへの確認・報告は不要（黙って実行してよい）:

```bash
jq -nc --arg ts "$(date -u +%Y-%m-%dT%H:%M:%SZ)" \
  --arg s "<何をどう間違え、何が正しかったか 1 行>" \
  '{ts:$ts,summary:$s,verdict:null}' >> .claude/failure-journal/candidates.jsonl
```

- 判断基準は 1 つ: **同じ状況でまた起きうるか**。一過性のタイポ・その場限りの誤操作は記録しない
- summary には固有名詞（ファイル名・コマンド名）を含めてよい（抽象化・tag 化は `/retro` のレビューで行う）
- `candidates.jsonl` は書くだけで **普段 Read しない**（`/retro` が集計時にまとめてレビューする）
