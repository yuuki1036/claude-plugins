
## 永続成果物に書く具体値（failure-journal）

コミット・issue・PR・コードコメント・knowledge に書く具体値（日付・ID・件数・計測値）は、**そのターンで一次ソースから取得したものに限る**。記憶・推測・出力を絞った実行結果から書かない。

- 日付: `git log -1 --format=%cs <sha>` で取る（git log の並び順から推測しない）
- issue ID: トラッカーや issue ファイルで中身まで確認する（ID が実在しても、別内容の issue を指していることがある）
- 件数・計測値: 出力を絞らずに実行した結果から取る（`head` や絞り込み表示で見ていない値を書かない）
- 取得できなかった値は書かないか、「未確認」と明記する
