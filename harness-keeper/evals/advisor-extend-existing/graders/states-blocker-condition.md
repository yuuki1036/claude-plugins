「新 skill に分けるべきブロッカー」を具体的な条件として扱っている。次のどちらかを満たせば PASS:

- 既存拡張ではなく新 skill が正当化される条件（例: トリガーが意味的に重ならない / allowed-tools が衝突する / 実行時間やコンテキスト消費が大きく常時ロードしたくない / 別モデル・別 effort で動かしたい / コミット以外の場面からも呼びたい）を 1 つ以上挙げ、この相談に当てはまるか当てはまらないかを個別に判定している
- 将来どうなったら分けるべきかを、上のような具体条件で述べている

ブロッカーの概念に触れていない、または「必要になったら分ける」程度の抽象的な記述しか無ければ FAIL。
