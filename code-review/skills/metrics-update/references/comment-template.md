# コメント・起票の本文

metrics-update の Step 5・6 で書く本文の型と、公開前の置き換え。投稿先の `yuuki1036/claude-plugins` は公開リポジトリで、投稿した本文は取り消せない（編集しても旧版が履歴に残る）。

## 本文の型

```markdown
## 計測の更新（YYYY-MM-DD）

<この issue の判定基準・再監視条件に対して、今回の数値が何を言うかを 1〜3 文。結論を先に>

| <比較表から、この issue に関わる行と列だけ> |
|---|

- 打ち手の前後: `--split-version <版>` で <版> より前 n=… / 以上 n=…（あれば）
- 判定: <基準を満たした / まだ（あと N 件）/ 崩れた>

<retro の「集計」行（逐語）>
<retro の「マシン / 版」行（逐語）>
```

- 数値は `metrics-update.sh` と retro の出力から写す。手で組み直した集計の値を書かない
- 「集計」行と「マシン / 版」行は要約せずにそのまま付ける。どの母集団・どの版で測ったかを後から復元するため（`orchestration-measurement.md ## 18`）
- 事象はイベントの `ts` で参照する
- 起票の本文は、上の型の後に「提案」の節（何をどう変えるか・効果の測り方・関連 issue）を足す。タイトルは `[code-review] <要約>`（`.title` のファイルには `<要約>` だけを書く）。タイトルにも置き換え表を当て、プレビューに出す（タイトルは本文より目に付き、検索と通知に載る）。`'` は使わない（投稿のコマンドで `'...'` に包む）

## 貼らないもの

- 語彙落ちの差分（落ちたキーの値・`other` になる前の値）。業務の語を含みうる。書くのは件数と `ts` まで
- `--show-paths` の出力・生のパス・`find` の結果
- 計測ストアのリポジトリ名・ファイルの中身。ストアのことは「計測ストア」と書く

## 置き換え表

本文ファイルに書く**前に**、書く内容（起票ならタイトルも）の全行へ当てる（置き換えた後の本文だけをファイルに書く。置き換え前の語を一度でもディスクに書くと、途中で止まったときに残る）。

| 種類 | 見分け方 | 置き換え後 |
|---|---|---|
| 業務リポジトリ名・製品名・社名・チーム名 | 公開されていないリポジトリの名前。会話・cwd・パスに出てきた組織名・製品名 | 「業務リポジトリ A」「業務リポジトリ B」…（同じものは issue をまたいで同じ記号）。製品名・社名・チーム名は書かない |
| 業務の PR・Issue の番号と URL | `<業務リポジトリ> PR #123`、業務の org の URL | 「業務 PR」（複数なら「業務 PR-1」「業務 PR-2」） |
| Issue トラッカーの ID（Linear など） | `ABC-123` 型の ID と、それを含むブランチ名 | `TEAM-123` |
| 端末名 | `hostname` の値、ユーザー名入りのマシン名 | マシンの label（`m1` / `m2`）。retro の出力はもともと label で出る |
| 業務コードの識別子・ドメイン用語 | 関数・画面・テーブルの名前 | 役割だけを表す汎用名（「関数 A」「ある画面」） |
| 業務のローカルパス | 業務リポジトリの置き場所を含む絶対パス、transcript のディレクトリ名（`-Users-<name>-<repo>` 型） | `~/<work>/...`。パス中のリポジトリ名も上の記号にする |
| 業務ドメインの説明・社内文書の引用 | 何を扱う製品か、業務リポジトリの規約・README・AGENTS.md の文面 | 書かない。要るなら「業務リポジトリの規約で〜と決まっている」と要旨だけにする |

- claude-plugins 自身の issue 番号・ファイルパスは置き換えない
- スクリプト・ツールの出力（比較表・retro の行）を貼るときは、貼る行ごとに表を当てる。パス・ホスト名はこの経路で混ざる
- 業務由来か迷った語は置き換える
- 固有名を消すと問題が伝わらないときは、その部分を書かずに利用者へ相談する

## 完了基準

- 本文の全行（起票ならタイトルも）を置き換え表の全行に照らしてからファイルに書いた
- プレビューの本文の外に「置き換えた種類と件数」を添えた（置き換え前の語はプレビューにも本文ファイルにも書かない）
- 本文ファイルを書く呼び出しと投稿の呼び出しを分けた（同じコマンドで本文を書き換えながら投稿しない）
