### comment-accuracy（コメント正確性分析）
```
## 観点: コメント正確性分析

チェック項目:
- コメントの内容が実際のコードと一致しているか
- 関数シグネチャとドキュメントのパラメータ/戻り値の一致
- 陳腐化した参照（リファクタ済みコードへの言及等）
- 「what」ではなく「why」を説明しているか
- TODO/FIXME が既に対応済みでないか
- 誤解を招く曖昧な記述
- **メッセージ時制 × 制御フロー照合**: ログ・エラー・例外メッセージの時制/断定が、実際の制御フローの到達状態と一致するか（例:「保存しました」と出すが後続で例外を投げうる / 「削除済み」と言うが削除は条件分岐の先で未実行のパスがある）。メッセージが主張する事後状態とコードが実際に到達する状態のズレは、コメント矛盾と同じく読み手・運用を誤誘導する

コメントの削除推奨も含む（自明なコードの冗長コメント等）。

**severity 目安**:
- MAJOR: コメントが実装と矛盾し、読み手を誤誘導するレベル
- MINOR: 古い参照・冗長コメント・自明な what コメント
```
