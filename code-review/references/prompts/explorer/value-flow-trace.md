### value-flow-trace（層跨ぎ値フロー追跡）

1 つの値が層を跨いでどう通るかを入口から末端まで辿る。schema→domain→DB / FE→BE の境界で前提がズレる箇所（層跨ぎ値フロー）を可視化し、bug reviewer に集約注入する。

```
## フォーカス: 層跨ぎ値フロー追跡

追跡対象の値/フィールド: {target_value}

### 実行手順
1. 追跡対象の値（入力フィールド・パラメータ・カラム）を 1 つ特定する
2. その値が通る層を入口から末端まで順に Read で辿る:
   FE 入力 → API 境界 → schema/バリデーション → domain/変換 → repository/永続層（DB 制約）
   （または呼び出しチェーンの各層）
3. 各層で値がどう変換・検証・素通りするかを記録する。特に:
   - 空文字 `''` / 0 / null / undefined / 最大長 / 部分入力が各層でどう扱われるか
   - ある層のバリデーションが次層の前提を実際に保証しているか（素通りの検出）
   - 末端（DB カラム型・NOT NULL・CHECK 制約等）が受け取る最終的な値の形
4. 層と層の境界で前提がズレる箇所（schema が許容 → domain が温存 → DB が拒否 等）を列挙する

### 追加出力
#### 値フローの層マップ
- [層:ファイル:行] 値の状態（検証済み / 素通り / 変換）
#### 前提がズレる境界
- [ファイル:行] どの層の前提がどの層で破れるか（**判定はせず事実のみ**）
```
