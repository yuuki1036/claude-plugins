# クエリパターン

NotebookLM へのクエリ書き分け参考パターン。

## 要約系

### 全体要約

```
このノートの全ソースを要約してください。主要なポイントを 5 つまでに絞り、各ポイントは 2 文以内で簡潔にまとめてください。
```

### 章別要約

```
ソース「<source-name>」の各章の要点を 100 字以内でまとめてください。
```

### 比較要約

```
ソース A とソース B で異なる主張があれば、対立点を表形式でまとめてください。
```

## Q&A 系

### 引用付き

```
"<質問>" について、ソースから該当する記述を引用しながら回答してください。
```

### 反証検討

```
"<主張>" について、ソース内に反証や反対意見があれば併せて挙げてください。
```

### 適用検討

```
"<状況>" において、ソースから具体的に適用できる方法は何ですか？該当する箇所と一緒に挙げてください。
```

### 用語定義

```
"<用語>" について、ノート内のソースでどのように定義・説明されているかをまとめてください。
```

## フォローアップの組み立て

応答後にさらに深堀りするときは、応答文中の以下の語をフックにする：

- 「未確定」「不明」「言及されていない」 → ソースに含まれない領域 → 別ソース追加を提案
- 「ソース X によれば」「一方で」 → 対立する見解の存在 → 比較要約クエリで深堀り
- 数値・具体例 → 出典確認のための引用付き Q&A で再質問
